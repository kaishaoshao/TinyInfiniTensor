### **项目结构**

#### **1.1 `core/` 目录**

- **核心模块**：包含项目的基础功能和核心逻辑。
  - **`allocator.cc`**：内存分配器的实现，用于管理张量和其他数据结构的内存。
  - **`data_type.cc`**：数据类型的定义和操作（如浮点数、整数等）。
  - **`graph.cc`**：计算图的实现，用于描述张量操作之间的依赖关系。
  - **`operator.cc`**：算子的基类或通用实现。
  - **`op_type.cc`**：算子类型的定义（如加法、乘法、卷积等）。
  - **`runtime.cc`**：运行时系统的实现，负责调度和执行计算图。
  - **`tensor.cc`**：张量的实现，包括张量的创建、存储和操作。

#### **1.2 `kernels/` 目录**

- **内核实现**：包含具体硬件平台（如 CPU）的算子实现。
  - **`cpu/`**：CPU 平台的算子实现。
    - **`concat.cc`**：张量拼接操作的实现。
    - **`element_wise.cc`**：逐元素操作（如加法、乘法）的实现。
    - **`transpose.cc`**：张量转置操作的实现。
    - **`unary.cc`**：一元操作（如取反、绝对值）的实现。

#### **1.3 `operators/` 目录**

- **算子实现**：包含具体算子的实现。
  - **`concat.cc`**：张量拼接算子的实现。
  - **`element_wise.cc`**：逐元素算子的实现。
  - **`matmul.cc`**：矩阵乘法算子的实现。
  - **`transpose.cc`**：张量转置算子的实现。
  - **`unary.cc`**：一元算子的实现。

#### **1.4 `utils/` 目录**

- **工具模块**：包含项目的工具函数和辅助功能。
  - **`exception.cc`**：异常处理的实现。
  - **`operator_utils.cc`**：算子相关的工具函数（如参数检查、类型转换等）。
